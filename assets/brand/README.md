# Identidade visual AGTN

- `agtn-logo-dark.svg` / `agtn-logo-light.svg` — **logotipo oficial** extraído em vetor do Manual da Marca AGTN
  (AGT + N azul `#125B9E` + “INDÚSTRIA METALÚRGICA”). Versão escura (AGT branco) para a interface; clara para fundo branco.
- `apps/desktop/public/brand/agtn-mark-dark.svg` — só a marca (sem subtítulo), usada na barra superior.
- `app-icon-source.png` — ícone do aplicativo (A geométrico com marcas de construção), base para
  `npx tauri icon assets/brand/app-icon-source.png -o apps/desktop/src-tauri/icons`.

Cores: azul AGTN `#125B9E`; interface grafite `#16181c`/`#1c1f24`, azul de destaque `#3d8bfd`.
