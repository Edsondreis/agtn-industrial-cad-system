# AGTN Industrial CAD 1.1.0

## Novidades
- **DWG**: abrir, importar e exportar arquivos DWG (AutoCAD R12 até 2018+).
- **Converter DWG ↔ DXF** direto do Start Center — vários arquivos de uma vez, nos dois sentidos, escolhendo a versão
  (R12, R14, 2000, 2004, 2007, 2010, 2013, 2018) e a pasta de destino. Os originais nunca são alterados.
- **Duplo clique abre no AGTN Industrial CAD**: o instalador registra `.agtncad`, `.dxf` e `.dwg`. Com o programa já
  aberto, o arquivo abre na mesma janela.

## Correção
- Perfil U com medidas válidas (ex.: abas 100, base 200, T 3, R 3) mostrava "a seção se autointercepta". Era erro
  numérico na verificação; o desenvolvimento e as medidas nunca foram afetados.

## Requisito para DWG
O DWG é um formato fechado. O AGTN Industrial CAD usa o **ODA File Converter** (gratuito, Open Design Alliance):
baixe em https://www.opendesign.com/guestfiles/oda_file_converter e instale — o AGTN CAD encontra sozinho
(ou aponte o `ODAFileConverter.exe` em Preferências → DWG). DXF e `.agtncad` não precisam de nada.

## Tornar o AGTN CAD o padrão
Se outro programa (AutoCAD, DWG TrueView…) já era o padrão de `.dwg`/`.dxf`, o Windows pede confirmação:
Preferências → "Padrão para .dwg" → escolha **AGTN Industrial CAD** → marque **Sempre usar este aplicativo**.

## Instalação
- **`AGTN Industrial CAD_1.1.0_x64-setup.exe`** — recomendado.
- `AGTN Industrial CAD_1.1.0_x64_pt-BR.msi` — MSI.
- `agtn-cad.exe` — sem instalação (sem associação de arquivos).
- `SHA256SUMS.txt`.
