# AGTN Industrial CAD 1.1.0

## Novidades
- **DWG direto no AGTN Industrial CAD** — abrir, importar e exportar DWG do AutoCAD R12 até 2018+, com
  **conversor próprio embutido**: não precisa instalar nem baixar nada.
- **Converter DWG ↔ DXF** no Start Center — vários arquivos de uma vez, nos dois sentidos, escolhendo a versão
  (R12, R14, 2000, 2004, 2007, 2010, 2013, 2018) e a pasta de destino. Os originais nunca são alterados.
- **Programa padrão** — o instalador pergunta se arquivos `.dwg` e `.dxf` devem abrir com duplo clique no
  AGTN Industrial CAD. Dá para mudar depois em Preferências → "Tornar padrão para .dwg / .dxf".
- Com o programa já aberto, o arquivo do duplo clique abre na mesma janela.

## Correção
- Perfil U com medidas válidas (ex.: abas 100, base 200, T 3, R 3) mostrava "a seção se autointercepta". Era erro
  numérico na verificação; o desenvolvimento e as medidas nunca foram afetados.

## Qualidade
DWGs reais do AutoCAD (R14 a 2018) abertos pelo AGTN CAD dão o mesmo resultado, objeto por objeto, que o DXF gerado
pelo próprio AutoCAD. Cada amostra é regravada e relida em 8 versões de DWG e 8 de DXF a cada build.

## Instalação
- **`AGTN Industrial CAD_1.1.0_x64-setup.exe`** — recomendado (pergunta sobre o programa padrão).
- `AGTN Industrial CAD_1.1.0_x64_pt-BR.msi` — MSI.
- `agtn-cad.exe` — sem instalação (use Preferências → "Tornar padrão" se quiser o duplo clique).
- `SHA256SUMS.txt`.

Componentes de terceiros: `docs/TERCEIROS.md` (acadrust — MPL-2.0; ACadSharp — MIT).
